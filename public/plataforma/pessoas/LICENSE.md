# Personagens 3D do escritório virtual

Os arquivos `*.glb` desta pasta são os personagens e as animações da **Microsoft Rocketbox Avatar Library**
(https://github.com/microsoft/Microsoft-Rocketbox), convertidos de FBX para glTF e reduzidos para a web
(texturas em 1024/512 px, animações a 15 quadros/s, só rotações + raiz).

| arquivo | personagem Rocketbox | agente |
|---|---|---|
| captador.glb | Business_Male_06 | TH-IA-GO |
| apartamentos.glb | Business_Female_01 | Ana |
| comerciais.glb | Business_Male_02 | Bruno |
| terrenos.glb | Business_Male_04 | Teo |
| casas.glb | Business_Female_03 | Clara |
| alto-padrao.glb | Business_Female_04 | Helena |
| offmarket.glb | Business_Male_05 | Vicente |
| gerente.glb | Male_Adult_03 | Augusto |
| gerente-corretores.glb | Business_Female_02 | Marta |
| visitante.glb | Male_Adult_01 | quem entra pela porta |
| anim-m.glb / anim-f.glb | all_animations_max_motextr_static + _xy | animações (idle, sentado, digita, anda, bebe, papel, fala, acena, celular, pensa, respira, olhar, alonga) |
